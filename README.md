# My Favorite Series: Squid Game

This is my first repository for application development.

## About Squid Game

**Squid Game** is a South Korean survival drama series where contestants play deadly children's games for a massive cash prize.

## Main Characters
- **Seong Gi-hun** (Player 456) - The main protagonist
- **Cho Sang-woo** (Player 218) - Gi-hun's childhood friend
- **Kang Sae-byeok** (Player 067) - A North Korean defector
- **Oh Il-nam** (Player 001) - The oldest participant

## The Games
1. Red Light, Green Light
2. Honeycomb (Dalgona)
3. Tug of War
4. Marbles
5. Glass Bridge
6. Squid Game

## My Favorite Quote
> "You don't trust people here because you can. You do it because you don't have anybody else."

## Why I Love It
- **Intense suspense** - Every episode keeps you on edge
- **Social commentary** - Shows economic inequality and human nature
- **Amazing characters** - Complex and well-developed personalities
